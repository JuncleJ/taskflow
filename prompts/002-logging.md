# TaskFlow — настройка логирования

Проведи анализ текущей реализации логирования в проекте TaskFlow и улучши её.

## Требования

1. Используй SLF4J + Logback. Если зависимости уже присутствуют, не дублируй их.
2. Создай или настрой `src/main/resources/logback.xml`.
3. Настрой вывод логов в консоль в формате: дата, время, уровень, поток, logger, сообщение.
4. Добавь возможность настраивать уровень логирования через переменную окружения `LOG_LEVEL`.
5. Добавь логирование входящих HTTP-запросов с методом, маршрутом, статусом ответа и продолжительностью.
6. Реализуй логирование жизненного цикла фоновых задач:
    - создание задачи;
    - начало выполнения;
    - успешное завершение;
    - ошибка выполнения.
7. В логах задач указывай `taskId`, `userId` и `taskType`, когда эти данные доступны.
8. Не логируй пароли, токены авторизации и другие чувствительные данные.
9. Не логируй каждый процент прогресса на уровне INFO, чтобы избежать избыточного количества сообщений.
10. Не блокируй Vert.x Event Loop операциями записи логов. Оцени необходимость асинхронного appender.
11. Не меняй бизнес-логику приложения без необходимости.
