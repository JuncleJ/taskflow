# TaskFlow — инструкции

## Контекст
TaskFlow — приложение для асинхронного выполнения фоновых задач с отслеживанием прогресса в реальном времени.

Проект разрабатывается в рамках тестового задания, целью которого является демонстрация навыков использования ИИ, анализа сгенерированного кода и его последующего улучшения.

## Технологии
- Java 21 (Eclipse Temurin)
- Vert.x
- PostgreSQL
- Gradle (Kotlin DSL)
- JUnit 5
- Docker Compose
- HTML, CSS, JavaScript

## Правила разработки
1. Документацию и объяснения пиши на русском.
2. Не используй Spring Boot и Hibernate.
3. Не блокируй Vert.x Event Loop.
4. Используй неблокирующие операции с PostgreSQL.
5. Разделяй HTTP-слой, бизнес-логику и работу с БД.
6. Не добавляй лишние зависимости и абстракции.
7. Не храни пароли и секреты в коде.
8. Для ключевой логики добавляй тесты.
9. При изменениях объясняй технические решения.

## Работа с ИИ
1. Перед реализацией изучай соответствующий файл из папки prompts.
2. Изменяй только то, что относится к текущему запросу.
3. После выполнения перечисляй изменённые файлы.
4. Сообщай результаты сборки и тестирования.
5. Не утверждай, что тесты прошли, если они не запускались.
6. Не создавай Git-коммиты без отдельной команды.
7. Не исправляй посторонние проблемы без согласования.
8. Не добавляй ошибки искусственно ради последующего рефакторинга.

## Цель
Получить работающее, понятное и расширяемое приложение, которое можно последовательно улучшать на основании реального Code Review.
